# FIFA 22 Player Analysis

## Project Overview
SQL analysis of 19,239 FIFA 22 players to find insights about market value, wages and nationality.

## Tools Used
- MySQL / MySQL Workbench
- Python (pandas, sqlalchemy) for data import

## 3 Questions Answered
1. Does age affect a player's market value?
2. Which position has the highest average wage?
3. Which country produces the highest rated players?

## Key Findings
1. Players peak in market value at age 24 (€3.7M average)
2. Multi-position players (LM, CF, LW) earn highest wages (€220K/week)
3. Smaller nations produce more consistently rated players on average

## Dataset
Kaggle FIFA 22 Complete Player Dataset
